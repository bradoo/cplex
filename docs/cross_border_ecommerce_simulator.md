# 跨境电商库存与运输模拟器

这个模拟器把跨境电商里的几个典型优化问题放在一个页面里：

- 仓库网络选择：开哪些海外仓，哪些市场由哪个仓履约
- 旺季缺口分析：需求上涨时，哪些市场会缺履约能力
- 临时扩容决策：扩容成本和丢单罚分哪个更划算
- 新市场进入决策：新国家市场先直邮试水，还是启用区域仓/本地 3PL
- 天气风险建仓选址：把极端天气和中断风险纳入仓库选址
- 补货计划：空运、海运、库存、缺货之间如何取舍
- 多供应商采购分配：采购价、起订量、交期和可靠性之间如何取舍
- 供应商评分体系：把基本信息、历史业务、风险、天气、售后和响应能力纳入采购优化
- 采购现金流约束：月度现金预算和供应商账期如何影响采购节奏
- 跨仓库存调拨：海外仓之间库存不均时，如何在调拨、补货和缺货之间取舍
- 物流服务组合：本地仓、经济直邮、加急直邮如何混合使用
- 关税政策敏感性：税率、免税门槛和清关成本变化时，路径如何切换
- SLA 敏感性分析：送达承诺从 3 天到 9 天时，成本和线路组合如何变化
- 多目标权衡：成本、时效、碳排和履约风险之间如何取舍
- 物流韧性预案：正常成本和故障不断供之间如何取舍
- 清仓折扣优化：库存积压时，如何选择折扣档并控制毛利损失
- 退货分级再销售：按成色把退货分配到最合适的再销售渠道
- 广告库存联动：广告预算、库存、毛利和履约能力一起优化

cd ~/cplex/python

## 演示顺序

### 1. 严格 SLA

仓网模式选择：

```text
严格 SLA
```

推荐参数：

```text
需求倍率: 1.0
SLA 放宽天数: 0
未履约罚分: 50
```

讲解重点：

```text
当客户要求较快送达时，模型会倾向于启用区域海外仓。
固定成本更高，但能满足 US West、US East、UK、EU 等市场的时效要求。
```

典型结果：

```text
启用 Los Angeles 3PL、New Jersey 3PL、Rotterdam EU Hub
未履约订单为 0
```

### 2. 旺季缺口分析

仓网模式选择：

```text
旺季缺口分析
```

页面会自动切到：

```text
需求倍率: 1.25
```

讲解重点：

```text
需求上涨后，如果不允许扩容，模型不会只说“无解”，
而是通过未履约变量告诉我们缺口在哪里。
```

典型结果：

```text
UK 出现 500 单未履约
Rotterdam EU Hub 接近或达到容量上限
```

### 3. 旺季临时扩容

仓网模式选择：

```text
旺季临时扩容
```

推荐参数：

```text
需求倍率: 1.25
未履约罚分: 50
```

讲解重点：

```text
模型会比较临时扩容成本和未履约罚分。
如果扩容更便宜，就选择给瓶颈仓库购买额外容量。
```

典型结果：

```text
Rotterdam EU Hub 临时扩容 500 单
未履约订单降为 0
```

### 4. 补货参数试验

可以调整：

```text
空运周容量
海运提前期周数
未履约罚分
```

推荐演示：

```text
把空运周容量从 900 调到 1200
```

观察：

```text
补货缺货会减少或消失，但运输成本会上升。
```

再试：

```text
把海运提前期从 3 调到 2
```

观察：

```text
便宜海运更早到货，通常比单纯增加空运更划算。
```

### 5. 多供应商采购分配

仓网模式选择：

```text
多供应商采购分配
```

讲解重点：

```text
最低采购价不等于最低总风险。
供应商会有产能、起订量、交期和可靠性差异。
模型会把订单拆给多个供应商，而不是简单选一家最便宜的。
```

核心建模方式：

```text
最小化总成本 = 采购成本
             + 供应商启用成本
             + 缺货罚分
```

关键约束：

```text
每个 SKU 要覆盖需求和安全库存；
供应商有产能上限和起订量；
平均交期不能超过目标；
平均可靠性必须达标。
```

观察：

```text
模型可能同时选择低价供应商、稳定供应商和本地备份供应商。
这不是“犹豫”，而是在满足交期和可靠性约束下做最低成本组合。
```

### 6. 供应商评分体系

仓网模式选择：

```text
供应商评分体系
```

讲解重点：

```text
供应商选择可以纳入评估表里的 9 类因素：
基本信息、历史业务、总评估等级、风险信息、地理位置和天气、
可靠性、售后服务、交货及时率、快速响应能力。
```

核心建模方式：

```text
最小化评分调整后成本 =
采购成本
+ 启用成本
+ 质量/法律风险成本
+ 天气/地理风险成本
+ 缺货罚分
- 服务与响应能力加分
```

关键约束：

```text
总评估等级、风险、可靠性、准时率、响应能力必须过门槛；
供应商有产能和起订量；
单一供应商占比不能过高；
每个 SKU 要覆盖需求和安全库存。
```

观察：

```text
低价但风险评分不达标的供应商会被排除；
合格供应商之间再根据成本、服务、天气风险和历史合作情况分配采购量。
```

### 7. 采购现金流约束

仓网模式选择：

```text
采购现金流约束
```

讲解重点：

```text
采购计划不是只看需求预测。
如果现金预算有限，模型要决定哪些 SKU 先买、哪些 SKU 延后买，
还要考虑供应商付款账期对下个月现金流的影响。
```

核心建模方式：

```text
最小化总成本 = 采购成本
             + 库存持有成本
             + 缺货罚分
```

关键约束：

```text
每月库存平衡；
每月现金支出不能超过预算；
采购付款按本月和下月账期拆分；
仓库总库存不能超过容量；
期末要保留最低库存覆盖。
```

观察：

```text
现金预算紧张时，模型可能优先买高风险或高缺货损失 SKU；
有些 SKU 即使有需求，也可能因为现金流约束被迫产生缺口。
```

### 8. 天气风险建仓选址

仓网模式选择：

```text
天气风险建仓选址
```

讲解重点：

```text
天气因素可以转成风险成本和风险约束。
比如飓风、暴雪、山火、港口风暴导致的停摆概率，
会影响仓库的预期中断订单和履约稳定性。
```

核心建模方式：

```text
最小化总成本 = 仓库固定成本
             + 履约成本
             + 天气风险成本
```

关键约束：

```text
每个市场需求必须满足；
仓库容量不能超过上限；
不满足 SLA 的线路不能使用；
高天气风险仓承接订单比例不能过高；
整体平均天气风险不能超过管理层设定的阈值。
```

观察：

```text
便宜仓不一定会被选中；
如果天气风险太高，模型会把订单分散到更稳的仓网组合。
```

### 9. 跨仓库存调拨

仓网模式选择：

```text
跨仓库存调拨
```

页面参数：

```text
选择这个场景后，右侧结果区顶部会出现“需求与库存参数”。
可以直接修改每个海外仓的初始库存和需求，再点击“重新求解”。
```

讲解重点：

```text
海外仓库存经常不均衡：有的仓爆仓，有的仓缺货。
模型会比较三种选择：
跨仓调拨、从国内补货、接受缺货罚分。
```

核心建模方式：

```text
最小化总成本 = 跨仓调拨成本
             + 国内补货成本
             + 缺货罚分
```

关键约束：

```text
每个仓库都要满足库存平衡；
跨仓调拨线路有容量限制；
国内补货总量有限；
期末库存和缺口都不能为负。
```

观察：

```text
模型会优先使用便宜、可行的近距离调拨；
跨洲调拨如果太贵，可能不如国内补货。
```

### 10. 关税政策敏感性

仓网模式选择：

```text
关税政策敏感性
```

讲解重点：

```text
跨境电商的物流路径不只受运费影响，也受关税、低价值免税政策、DDU/DDP 清关成本影响。
政策变化后，原来便宜的直邮 DDU 可能变贵，模型会重新选择保税仓或 DDP 路径。
```

核心建模方式：

```text
每个政策情景下：
最小化总成本 = 路径固定成本
             + 国际运费
             + 关税
             + 清关/合规成本
```

观察：

```text
基准政策下可能更多走 DDU；
当 DDU 合规成本上涨时，模型会把部分订单切到 DDP Express；
当低价值免税取消时，总成本会明显上升。
```

### 11. 新市场进入决策

仓网模式选择：

```text
新市场进入决策
```

讲解重点：

```text
进入新市场时，不一定一开始就要开本地 3PL。
如果订单量还不够大，固定成本可能吃掉本地履约节省的变动成本。
模型会在直邮试水、区域仓履约、本地 3PL 之间分配订单。
```

核心建模方式：

```text
最大化净贡献 = 销售毛利
             - 履约变动成本
             - 市场进入固定成本
```

观察：

```text
模型可能选择“部分直邮 + 部分区域仓”，既满足快速履约比例，又避免太早承担本地 3PL 固定成本。
```

### 12. 多目标权衡

仓网模式选择：

```text
多目标权衡
```

讲解重点：

```text
真实业务里通常不是单目标。
如果只看成本，模型会偏向便宜但慢的经济线路；
如果提高速度、碳排或风险的权重，模型会把部分订单切到海外仓或加急线路。
```

核心建模方式：

```text
总评分 = 物流成本
       + 速度权重 × 总送达天数
       + 碳权重 × 碳排放
       + 风险权重 × 预计风险订单
```

观察：

```text
同一批市场需求和路线容量下，权重不同，最优线路组合也不同。
这就是业务上说的“策略偏好”如何进入优化模型。
```

### 13. SLA 敏感性分析

仓网模式选择：

```text
SLA 敏感性分析
```

讲解重点：

```text
SLA 不是一句“越快越好”。
承诺 3 天、4 天、8 天、9 天，对成本和线路选择的影响完全不同。
这个例子会批量求解多个送达承诺档位，形成一条成本曲线。
```

观察：

```text
3 天承诺可能无解；
4-6 天通常需要本地仓或 DDP 加急；
8-9 天可以使用更多直邮，成本会明显下降。
```

适合对业务方说的一句话：

```text
每缩短一天承诺，都不是改一句页面文案，而是在改变履约网络和成本结构。
```

### 14. 物流韧性预案

仓网模式选择：

```text
物流韧性预案
```

讲解重点：

```text
精益方案只看正常月份的最低成本；
韧性方案会提前预留备份线路或备用仓容。
平时看，韧性方案可能多花一点钱；
但在海关延误、干线容量下降、旺季爆仓时，它能显著减少缺口。
```

核心建模方式：

```text
精益方案目标 = 正常履约成本

韧性方案目标 = 正常履约成本
             + 备份能力预留成本
             + 故障场景缺口罚分
```

观察：

```text
如果没有提前预留，故障时可能无法临时启用备份线路。
模型会把“平时省的钱”和“出事时缺货的损失”放在一起比较。
```

### 15. 清仓折扣优化

仓网模式选择：

```text
清仓折扣优化
```

讲解重点：

```text
清仓不是所有商品统一打 8 折。
不同 SKU 对折扣的需求弹性不同，库存压力和毛利也不同。
模型会给每个 SKU 选择一个折扣档，平衡销量提升、毛利损失、持有成本和品牌折损。
```

核心建模方式：

```text
最大化净贡献 = 销售收入
             - 商品成本
             - 剩余库存持有成本
             - 深折扣品牌罚分
```

观察：

```text
季节款可能需要深折快速消化；
小配件轻折就能带动销量；
毛利健康且库存压力不大的 SKU 可能不该打折。
```

### 16. 退货分级再销售

仓网模式选择：

```text
退货分级再销售
```

讲解重点：

```text
退货不是统一翻新或统一报废。
同一个 SKU 的 A/B/C 成色，适合的处理渠道不同。
模型会在正价翻新、Outlet、批发清仓和回收之间分配退货。
```

核心建模方式：

```text
最大化回收价值 = 再销售价值 - 检测/翻新/处理成本
```

关键约束：

```text
每个退货批次必须被处理；
每个渠道有处理容量；
C 级品不能进入正价翻新渠道。
```

观察：

```text
高成色、高价值商品会优先占用正价翻新能力；
低成色商品通常进入 Outlet、批发清仓或回收。
```

### 15. 广告库存联动

仓网模式选择：

```text
广告库存联动
```

讲解重点：

```text
广告投放不能只看 ROAS。
如果库存不足或履约能力不足，广告带来的需求可能变成缺货和差评。
模型会把广告预算、库存、毛利和履约能力放在同一个决策里。
```

核心建模方式：

```text
最大化净贡献 = 毛利
             + 品牌增益
             - 广告花费
             - 缺货损失
```

关键约束：

```text
每个 SKU 只能选择一个广告档位；
总广告预算有限；
强投 SKU 数量有限；
销量不能超过库存和履约能力。
```

观察：

```text
高毛利 SKU 不一定强投，如果库存或履约能力卡住，模型会降低投放档位；
低毛利 SKU 即使库存充足，也可能不值得投广告。
```

## 页面指标怎么读

| 指标 | 含义 |
|---|---|
| 仓网总成本 | 仓库固定成本 + 履约变动成本 + 扩容/缺口相关成本 |
| 未履约订单 | 当前仓网和约束下无法满足的订单量 |
| 补货总成本 | 空运/海运成本 + 持有成本 + 缺货罚分 |
| 服务组合成本 | 本地仓、经济直邮、加急直邮混合后的总成本 |

## 适合对业务方说的一句话

```text
这个模拟器不是预测销量，而是在给定销量、仓容、运费和时效要求后，
计算怎样开仓、分仓、补货和选择物流服务，能让总成本或损失最小。
```
